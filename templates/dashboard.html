Overview · Dashboard

EPCM Guide · Netherlands pilot

Hi-Engineer is the ingest + enrichment layer feeding the public epcmguide.com directory. This page is the one-glance view of pipeline health: how many companies, how much contact + enrichment coverage, how many jobs and news items are flowing through to the directory and jobs board.

New here? → how this app works (click to expand)
Ingest → Scraping Engine pulls trade-show exhibitors; Content Engine pulls industrial media portals.
Directory → Companies list is the master. Contacts are role-tagged people. Taxonomy is the canonical 10-category tree.
Content → Jobs + Articles tabs show scraped items, each with role / topic filter chips mirroring the taxonomy.
Operations → Export sends data to Airtable / Softr / CSV. Stats + Logs show pipeline health and run history.
