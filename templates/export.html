Operations · Export

Export to Airtable, Softr, CSV

Pull live data out of Hi-Engineer for downstream use. The CSV downloads stream the current state of each entity. The Airtable schema is a JSON file you paste into Airtable's "Create base from JSON" flow (or feed to Softr, which sits on Airtable).

CSV downloads

UTF-8 CSV, one row per record. Opens cleanly in Excel/Numbers.

  • Companies.csv
  • Contacts.csv
  • Jobs.csv
  • Articles.csv

Airtable base schema

Includes Companies · Contacts · Jobs · Articles tables with their Airtable field types (singleSelect, email, url, etc.) pre-defined.

airtable_schema.json

Softr / portal integration

Softr reads Airtable directly. Create an Airtable base from the schema above, then sync CSVs via Airtable's import. For the public portal, Softr's prebuilt list / detail / filter components match the schema.
