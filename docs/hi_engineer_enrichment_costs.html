7How to run it

Six steps, cheapest and safest first

Each paid step starts with a 20-record test, so the real hit rate and cost are known before the full run.

  1. Switch Apollo off by default

    One setting, no code change: heroku config:set ENABLE_APOLLO=false -a hi-engineer-app. Keep Apollo for targeted use only.

    $0
  2. Free checks first

    Page check and jobs/news pipelines on the 1,951 companies with a website.

    $0
  3. IcyPeas on the 1,876 imported companies

    Test 20, compare fields filled, then run all.

    ≈ $1.30
  4. Contact emails with IcyPeas

    Test 50 (the pilot in the roadmap), verify the found emails, then the rest in weekly batches.

    ≈ $8
  5. Claude for categories, specialities and tags

    Needs an Anthropic API key (none is configured yet). Test 20 of each and review, then submit as one batch job.

    ≈ $3
  6. Firecrawl search for the 301 "nothing found"

    Inside the free monthly credits; test 20, then run the rest.

    $0
!

Development needed for steps 4–6. The contact email finder, the Claude classification and the Firecrawl website search are not built into the app yet; today's chain only enriches companies. Steps 1–3 can run now.

8Assumptions

What these numbers rest on

Measured in this project

  • 2,547 enrichment attempts, May–July 2026: IcyPeas 70% hit rate at $0.0007 per attempt; Apollo 22% at $0.047; page check 63%, free.
  • Field gaps and text lengths read from the live database on 9 October.
  • Apollo prices in the logs use the code's assumption of $0.05 per credit.

Estimated

  • Contact email find rate of 50%; the 50-contact pilot will measure it.
  • Claude token counts from average text length (about 4 characters per token), including some thinking; real cost could be ±50%, still under $5.
  • Unknown yield for Firecrawl website search.
  • Which IcyPeas and Apollo plans are active — check both dashboards.

Price sources (checked 9 October 2026):

  • IcyPeas pricing — Basic $19/month for 1,000 credits; email finder 1 credit per found email; verifier 0.1; find companies 0.02 per result.
  • FullEnrich pricing — Pro €55/month for 1,000 credits; work email 1 credit, charged only when found.
  • Clay pricing — Launch $167/month for 2,500 data credits; waterfall cost estimates.
  • Firecrawl pricing — free plan 1,000 credits/month; search 2 credits per 10 results.
  • Apollo (prices not published on its own page): 11x guide, Valley guide — Basic $49–65 per user/month, 1 credit per email, $0.20 overage.
  • Claude API: Opus 5.5 $4 / $20 per million input / output tokens; Batch API 50% off.
